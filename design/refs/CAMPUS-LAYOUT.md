# CAMPUS-LAYOUT — Tata Letak Kawasan

**Sumber utama:** `images/campus-satellite.png` (gambar satelit kawasan).
**Fungsi file ini:** acuan tertinggi untuk posisi dan hubungan antar elemen kawasan.

## Elemen Kawasan

| Elemen | Keterangan |
|---|---|
| Gerbang | Titik masuk kawasan |
| Turunan | Jalur menurun dari gerbang menuju area gedung |
| Lobby asrama | Area masuk gedung asrama |
| Gedung asrama | 5 lantai (B2, B1, LT 1–3) |
| Gedung sekolah | 3 lantai (LT 1–3) |
| Jalur penghubung | Jalur antar gedung |

## Hubungan yang Harus Dipertahankan

- Gerbang → turunan → lobby asrama → gedung asrama.
- Hubungan antara gedung asrama dan gedung sekolah melalui jalur penghubung.
- Posisi relatif gedung sesuai gambar satelit (arah, jarak relatif, dan orientasi).
