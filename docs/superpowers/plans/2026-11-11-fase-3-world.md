# Fase 3: Dunia Sekolah Virtual Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun seluruh fitur Fase 3 ("Konsep Dunia Sekolah Virtual" 3.1 s.d. 3.8 dalam `docs/rancangan.md` dan Tahap 1-2 `WORLD.md`): navigasi first-person 3D lorong sekolah tengah malam low-poly di `/dunia`, kontrol jalan/lari/jongkok dengan pergerakan kamera halus, raycast interaksi objek 3.2 (<2.5m) dengan HUD prompt ala VHS (`[E] AKSI`), panel overlay 2D interaktif (Pintu kelas, Mading, Perpustakaan, Loker, Cermin), Menu Jeda dengan sakelar ON/OFF, pasca-proses VHS adaptif, dan interoperabilitas penuh dengan Mode Cepat (2D).

**Architecture:**
- **Store & State**: Ekstensi `useWorldStore` untuk melacak posisi/fase, objek interaktif, modal aktif, dan sinkronisasi pengaturan grafis/audio/waktu.
- **Canvas & Scene (R3F)**: `WorldCanvas` (client-only dynamic import dengan fallback WebGL), memuat scene lorong sekolah low-poly liminal (`SchoolHallwayScene`) lengkap dengan baked-style lighting, neon strips, mading, loker, cermin, pintu kelas, dan perpustakaan.
- **Controls & Physics**: `PlayerController` kustom berbasis PointerLock + Keyboard/Touch, collision boundary clamps, serta crouch camera height transition (1.6m ke 0.9m).
- **Interaction System**: `RaycastDetector` yang menembakkan raycast dari kamera tengah layar, mengaktifkan HUD label `[E] AKSI` pada jarak <= 2.5m.
- **Overlay & HUD**: Lapisan antarmuka 2D retro-liminal (`WorldHud`, `PauseScreen`, `WorldModals`) dengan tipografi `VT323`, border solid 1px, tanpa emoji, dan dukungan keyboard/touch.

**Tech Stack:** Next.js (App Router), React 19, TypeScript, Three.js, @react-three/fiber, @react-three/drei, @react-three/postprocessing, postprocessing, Zustand, Tailwind CSS, Lucide-react, Vitest.

**Spec:**
- `docs/rancangan.md` (Bagian 3.1 s.d. 3.8)
- `WORLD.md` (Spesifikasi Dunia 3D Sekolah Tengah Malam)
- `DESIGN.md` (Token warna, tipografi, HUD kamera VHS, larangan AI-slop)
- `PRODUCT.md` (Aturan akurasi kawasan SMK TI BAZMA & 4 fase waktu)

## Global Constraints
- Token warna wajib dari `DESIGN.md`: `--night` (`#0B0D12`), `--fluor` (`#E9F2E3`), `--caution` (`#F2C200`), `--neon-cyan` (`#5CE1FF`), `--neon-pink` (`#FF5C93`), `--alert` (`#E0412F`), `--ok` (`#4FD08A`).
- Tipografi: `VT323` untuk label sistem & HUD, `Anton` untuk penunjuk/rambu, `Instrument Sans` untuk isi teks panel, `JetBrains Mono` untuk status.
- Dilarang memakai emoji sebagai ikon atau elemen dekoratif antarmuka (wajib SVG atau Lucide-react).
- Performa: target 60 FPS desktop, 30 FPS mobile, draw call rendah, instancing pada objek modular, tekstur low-poly.
- Aksesibilitas: dukungan `prefers-reduced-motion`, fallback otomatis ke Mode Cepat 2D jika WebGL gagal, kontrol keyboard & sentuh.

## Review Focus
1. Kegagalan inisialisasi WebGL pada perangkat tanpa GPU: wajib menampilkan fallback Mode Cepat yang elegan tanpa blank screen atau unhandled error.
2. Penanganan Pointer Lock pada browser (misal saat ditekan Esc atau saat panel 2D dibuka): kontrol kamera harus otomatis jeda dan kursor mouse muncul kembali secara mulus.
3. Transisi kamera saat jongkok (Ctrl/C): tinggi kamera bertransisi mulus dari 1.6m ke 0.9m dan kembali tanpa clipping atau pergerakan patah-patah.
4. Jarak interaksi raycast: tidak boleh memicu interaksi jika jarak melebihi 2.5m atau arah pandang tidak menghadap objek.
5. Menu Jeda dan sakelar ON/OFF: sakelar Mode Cepat, Suara, Antarmuka, dan Grafis harus langsung mengubah perilaku dunia 3D secara reaktif tanpa perlu refresh halaman.
